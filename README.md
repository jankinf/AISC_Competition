# AISC人脸识别对抗攻击竞赛项目

## 项目目标
通过生成对抗样本欺骗人脸识别系统，降低模型对配对人脸图像的识别相似度（余弦相似度）。

## 核心方法与思路

### 1. **基于关键点的局部扰动（Keypoints-based Mask）**
- 使用人脸关键点检测定位眼睛、鼻子、嘴巴等敏感区域
- 仅在这些关键区域添加扰动，控制扰动面积约10%
- 避免全局修改，提高攻击的隐蔽性

### 2. **多模型集成攻击**
- 同时对多个人脸识别模型（CurricularFace、face_evoLVe、PFR、TC_Rank4等）生成对抗样本
- 提高攻击的迁移性，使对抗样本在未知模型上也有效

### 3. **输入变换增强技术**
- **DI（Diversity Input）**：输入多样性变换
- **SI（Scale Invariant）**：尺度不变性变换  
- **TI（Translation Invariant）**：平移不变性（高斯核卷积）
- 组合使用DI+SI提升对抗样本鲁棒性

### 4. **特征填充策略（Feature Fill）**
- 在mask区域填充配对图像的特征
- 使原图向配对图的特征空间靠近，增强攻击效果

### 5. **黑盒优化策略**
- 使用白盒模型（可获取梯度）生成对抗样本
- 在黑盒模型上进行验证和选择最优样本
- 采用余弦调度动态调整学习率

### 6. **主要攻击算法**
- **基础方法**：DIM、DEM、MIM、AA
- **优化方法**：optmask系列（CT、PICT、ANDA等）
- **最终方法**：beval_ct_cos_catfeat_fill（结合余弦调度+特征连接+填充策略）

## 技术亮点
✓ 精准定位攻击区域，扰动小而有效  
✓ 多模型集成+输入增强保证迁移性  
✓ 白盒攻击+黑盒评估的混合优化策略  
✓ 动态学习率调整提升收敛效果
